# Tracy (Yuqing) Du — Portfolio

Live website: https://tracy-dyq.github.io/

This is the public deployment source. Edit content/site.json to update your biography, publications, projects and courses. Put replacement media into assets/ and reference their relative paths from JSON.

The homepage cover uses profile.hero. Each project has its own cover and detail content. Projects may use blocks of type text, image, video, link or issuu. Video blocks have title, summary, provider and src.

GitHub Pages: main branch, root folder. The empty/static .nojekyll file disables Jekyll. No build tools are needed.

The EEG cap video is a compressed web copy; its original remains in the local development project. Source design files and unused media are excluded from this deployment.
